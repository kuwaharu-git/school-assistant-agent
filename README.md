# School Assistant Agent

プログラミングスクールのための学習支援AIエージェント  
AI Assistant Agent for Programming School Education

## 概要 / Overview

このプロジェクトは、プログラミングを学ぶ学生の理解を深めるためのAIアシスタントエージェントです。直接的な答えを提供するのではなく、段階的なヒントと質問を通じて、学生の思考プロセスを促進し、自己解決能力を育成します。

This project is an AI assistant agent designed to deepen understanding for students learning programming. Rather than providing direct answers, it facilitates students' thinking processes and develops self-solving abilities through step-by-step hints and questions.

## 主な機能 / Key Features

- 📚 **段階的な学習支援** / **Progressive Learning Support**: ソクラテス式対話による思考の誘導
- 💬 **質問対応** / **Question Response**: 自然言語での質問受付と理解度に応じたヒント提供
- 🔍 **コードレビュー** / **Code Review**: 建設的なフィードバックとベストプラクティスの提案
- 📊 **学習進捗管理** / **Learning Progress Tracking**: 学生の成長と弱点の可視化
- 👨‍🏫 **講師支援** / **Instructor Support**: 学生の状況把握と介入タイミングの通知
